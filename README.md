# RCU-Website

Website der Rilkio Controller Utility (RCU): Download, Registrierung, Anmeldung, Infos zu RCU und Rilkio.
Statische Seite (HTML/CSS/JS) für GitHub Pages. Konten laufen über dasselbe Supabase-Projekt wie die RCU-App.

- `js/config.js`: Supabase-Adresse und öffentlicher Schlüssel, Download-Link
- `download/`: Setup-Datei der RCU
- `supabase/005-bewertungen.sql`: Tabelle für Bewertungen (einmal im SQL Editor ausführen)
